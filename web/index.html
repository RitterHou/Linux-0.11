和 QEMU 有什么不同

      
硬件是 v86 模拟的，第 1 行的硬盘型号是它报给内核的名字。CPU 的速度、定时器的节奏和 QEMU 不一样，开机和 ps 里的数字会略有出入。写硬盘只写在浏览器的内存里，重新开机就回到 make 生成时的样子。

    

    

      
和介绍网页有什么不同

      
介绍网页的屏幕是 JavaScript 写的模型：文件系统取自镜像，shell 照着 user/sh.c 用 JavaScript 重写了一遍，没有执行内核的指令。这一页执行的是内核本身，模型里省掉的东西这里都有，比如内存的数字会变、真的会缺页和写时复制。

    

    

      
怎么打开这一页

      
在仓库里运行 make web：它先构建镜像，下载固定版本的 v86（核对 sha256），把它们和这一页、介绍网页放进 build/web/，再起一个本地服务器。浏览器打开它打印的地址。直接双击 html 文件打不开：浏览器不让 file:// 页面读取镜像。
